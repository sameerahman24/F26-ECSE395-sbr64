# Making the LED on ESP32 Blink
## Intro
This is actually not my first time with an ESP32 development board, I did this before for a research lab I was part of. Professor Fu has asked us to make the LED on the ESP32 blink and if it's something cooler we get extra points. I am writing the code on VSCode and pushing it into the board using PlatformIO.

## Steps
 1. Connect the ESP32 to the laptop
 2. I already had platformIO installed so I just clicked on the ant icon and made a new project.
 3. Copy pasted the skeleton code and edited on it with the given instructions
 4. Uploaded that code to the board to verify it worked
 5. Once verified I had some fun setting up a custom blink
 6. 3 quick blinks -> 3 long blinks -> 3 quick blinks - this means SOS in morse code
